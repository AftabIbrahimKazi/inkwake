# Strata CSS — Learnings

- **2026-08-24 (strata-css ^1.8.17):** `[data-st-visible]` and `[data-st-collapsed]` are core, built-in state attributes (defined in `src/layers/base.js`) with their own baked-in CSS transitions (opacity+translateY fade for visible, max-height collapse for collapsed) — **no plugin/package needed**. Just set the attribute value from your own JS (`element.dataset.stVisible = 'true'`) and Strata's core CSS handles the animation. This is the correct way to build dropdowns/mega-menus/accordions/off-canvas panels in a Strata project — there is no pre-built `.navbar`/`.dropdown-menu`/`.offcanvas`/`.accordion` component in strata-css core (only `Modal`, `Skeleton`, `Chart` ship as real JS components, each pulled from `packages/` only if actually used). Don't go hunting for a Bootstrap-style nav component that doesn't exist — build the interaction with a tiny custom click/hover handler flipping `data-st-*` attributes, and let Strata's own transitions animate it.
- **2026-08-24:** `data-st-theme` genuinely supports `"dim"` as a first-class literal value at the core level (`[data-st-theme="dim"]` selectors exist in `base.js`) — unlike Bootstrap, no shade-splitting workaround is needed to get a working 3-theme (light/dark/dim) toggle. Just cycle the attribute directly.
- **2026-08-24:** `border-color` has **no arbitrary-bracket form** (`coverage.js` lists it under "ONLY named utilities") — for an arbitrary border color, use the full `border-[…]` shorthand (e.g. `border-[1px_solid_var(--x)]`) instead of trying `border-color-[…]` (doesn't exist).
- **2026-08-24:** `grid-template-columns`/`grid-template-rows` arbitrary utilities (`gtc-[…]` / `gtr-[…]`) accept comma-containing values fine, e.g. `gtc-[repeat(4,1fr)]` — commas don't need escaping/underscoring the way spaces do.
- **2026-08-24:** No `a { text-decoration: … }` base-reset rule exists anywhere in Strata's own compiled output (confirmed via grep on `strata.output.css`) — unlike Bootstrap, a project's own `a { text-decoration: none }` reset is safe from Strata's cascade-order and won't need the compound-selector specificity workaround that Bootstrap requires.
